# AI Customer Support Agent

An agentic AI customer-support system for NovaMart.

## Project Goals

- Understand customer requests
- Retrieve customer and order information
- Apply the correct support policies
- Handle refunds, returns, cancellations and support requests
- Ask for clarification when information is missing
- Escalate cases that require human review
- Verify actions before responding to the customer

## Tech Stack

- Python
- FastAPI
- React
- MongoDB
- AI/LLM
